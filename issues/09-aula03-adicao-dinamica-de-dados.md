# [Aula03] Adição dinâmica de dados no servidor

Adicione um quarto paciente no array em memória do `server.js`. Recarregue a página do frontend e confirme a atualização **sem mexer no código do cliente**.

**Critérios de aceite**

- [x] Quarto paciente (`Carlos Lima`) adicionado ao array do servidor.
- [x] Ao reiniciar o servidor e recarregar o frontend, a tabela exibe os 4 pacientes.
- [x] Nenhum arquivo do `frontend/` foi alterado para isso.

**Conclusão:** o frontend apenas consome o que a API devolve; quem manda nos dados é o servidor.
